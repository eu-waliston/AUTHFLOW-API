Funcionalidades

Tudo que você precisa em uma API de autenticação

Recursos robustos e testados, prontos para escalar com seu negócio.

🔑

JWT + Refresh Tokens

Autenticação stateless com tokens de acesso e refresh tokens com expiração configurável.

🛡️

Roles & Permissões

Controle de acesso baseado em roles (admin/user) com permissões granulares por endpoint.

👥

CRUD de Usuários

Gerenciamento completo de usuários com validação de dados usando Joi.

⚡

Rate Limiting

Proteção contra ataques de força bruta com rate limiting via Redis.

🔒

Segurança Avançada

Bcrypt com salt, Helmet, CORS configurável e sanitização de inputs.

📊

Logging Estruturado

Logs com Winston prontos para integração com ferramentas de monitoramento.

API Reference

Endpoints simples e intuitivos

RESTful, versionada e fácil de integrar com qualquer stack.

POST/api/auth/registerRegistrar novo usuário
POST/api/auth/loginAutenticar usuário
POST/api/auth/refreshRenovar access token
POST/api/auth/logoutEncerrar sessão
POST/api/auth/forgot-passwordSolicitar reset de senha
GET/api/usersListar usuários (admin)
GET/api/users/:idBuscar usuário por ID
PUT/api/users/:idAtualizar usuário
DELETE/api/users/:idRemover usuário (admin)
PUT/api/users/:id/roleAtualizar role (admin)
GET/api/profileVer meu perfil
PUT/api/profileAtualizar meu perfil
PUT/api/profile/passwordAlterar minha senha
cURL 
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "SecurePass123!",
    "role": "user"
  }'
Deploy

Pronto para produção em minutos

Escolha a estratégia que melhor se adapta ao seu ambiente.

🐳

Docker Compose

Suba API, PostgreSQL e Redis com um único comando.

docker-compose up -d
☸️

Kubernetes

Escalone horizontalmente com múltiplas réplicas e secrets.

kubectl apply -f deployment.yaml
⚙️

PM2 + Nginx

Deploy tradicional com process manager e reverse proxy.

pm2 start dist/app.js
